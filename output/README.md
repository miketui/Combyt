# Output — Generated CAD Files

This folder contains CAD files generated by the TAYLKOMB MCP pipeline.  
**Always use files from here** — never from `reference/`.

## Folder Convention

Each sweep gets its own subfolder:

```
output/
├── sweep_a/          ← Tight tolerance (current)
│   ├── step/         ← STEP files — use for manufacturing & CAD import
│   ├── stl/          ← STL files — use for 3D printing & preview
│   ├── reports/      ← Per-variant markdown reports
│   ├── metrics/      ← Measurement + validation JSONs
│   └── release_packs/← Zipped bundles (STEP+STL+report+metrics)
├── sweep_b/          ← Nominal tolerance (future)
└── sweep_c/          ← Loose tolerance (future)
```

## File Naming

Format: `{part_name}_{variant_id}.{ext}`

Example: `main_comb_A_main_01.step`
- Part: `main_comb`
- Sweep: `A` (tight)
- Variant number: `01`

## Which file to use?

| If you need... | Use this |
|----------------|----------|
| Import into Fusion/SolidWorks/FreeCAD | `step/*.step` |
| 3D print a test piece | `stl/*.stl` |
| Check if a variant passed validation | `metrics/*_validation.json` |
| See bounding box / mass / dimensions | `metrics/*_metrics.json` |
| Human-readable summary | `reports/*_report.md` |
| Send everything to a manufacturer | `release_packs/*_release.zip` |
